# أنا مسلم

موقع عربي RTL باستخدام Next.js 16 وReact 19 وnpm. يعمل بالمحتوى المضمّن دون حسابات أو مفاتيح، وفق اختيار المستخدم. جُهّز مخطط Supabase واستيراد البيانات للربط لاحقًا.

## التشغيل

```sh
npm ci
npm run dev
```

```sh
npm run typecheck
node scripts/validate-content.mjs
npm run build
```

الإخراج الثابت في `out/`. لأن `output: export` مفعّل، استضف هذا المجلد على خادم ملفات ثابتة؛ `next start` ليس وضع تشغيل هذه النسخة. تشغيل التطوير على منفذ آخر: `npm run dev -- --port 3001`.

## المحتوى والتغطية

- القرآن: ١١٤ سورة و٦٢٣٦ آية والتفسير الميسر، من Al Quran Cloud؛ النصوص محفوظة دون تحرير. التلاوة الخارجية بصوت مشاري العفاسي تحتاج الإنترنت.
- الأحاديث: جميع مواد ملف HadeethEnc العربي v1.7.0، المؤرخ 2025-11-12، وعددها ٣٥٨٢ **مادة**. بعضها روايات متعددة أو آثار، ولا يعني هذا العدد أحاديث فريدة أو استيعاب الصحيحين. العرض الافتراضي يقتصر على الحكم الصريح «صحيح» وأشكاله المحددة، وعدده ٣٢٢٤ مادة. الحسن ٢٧٥، والأحكام المركبة وغيرها ٨٣. الحكم الكامل محفوظ ويظهر في التفاصيل.
- حفظت الحقول الأصلية التسعة: المعرّف والعنوان والنص والشرح ومعاني الكلمات والفوائد والحكم والتخريج والرابط. لم نستبدل شروح المصدر بشروح مولّدة. أضيفت طبقة تصنيف من واجهة المصدر الرسمية؛ ٨ مواد لا توجد في التصنيف الحالي وتظهر تحت «غير مصنّف».
- قصص الأنبياء: ٢٥ ملفًا و٩٢ فصلًا، مع ١٧٩٧ إحالة إلى آيات (تشمل تكرار الآية عبر الملفات) و٤١ إحالة حديثية. تضم المقاطع القرآنية كاملة وتفسيرها، والأحاديث المختارة كاملة وشروحها. السرد التمهيدي تحرير بشري الشكل مولّد في هذه المهمة، يحتاج مراجعة علمية قبل ادعاء الاعتماد النهائي. لا تستوعب الملفات كل روايات التاريخ والسيرة، ولا تُملأ الفجوات التاريخية بقصص متخيلة.
- لا يوجد ضمان دقة بنسبة ١٠٠٪ أو ادعاء جمع كل أحاديث النبي. لم تُدمج نسخة أخرى للصحيحين وُجدت بها حقول نصية فارغة (٩ في ملف البخاري و٢٠٣ في ملف مسلم).
- رابط مقارنة تفسير ابن كثير هو للمراجعة الخارجية، وليس محتوى مستوردًا أو تصحيحًا لكل رواية ينقلها التفسير.

## Supabase لاحقًا

1. أنشئ مشروعك ونفّذ `supabase/schema.sql` في محرر SQL. جميع الجداول للقراءة العامة فقط، ولا توجد سياسات كتابة للمتصفح.
2. لاستيراد البيانات، ضع `SUPABASE_URL` و`SUPABASE_SERVICE_ROLE_KEY` في بيئة عملية الاستيراد المحلية، ثم شغّل `node scripts/seed-supabase.mjs`. السكربت يعيد استيراد السجلات بمعرّفاتها دون حذف غيرها، ويتوقف عند أول خطأ. لا تشارك المفتاح الإداري ولا تستخدمه مع `NEXT_PUBLIC`.
3. للقراءة المباشرة للأذكار والأدعية والقرآن، انسخ `.env.example` إلى `.env.local` وضع رابط المشروع و`NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` العام ثم أعد البناء. عند فشل الاتصال تظهر النسخة المضمّنة مع تنبيه.
4. مكتبة الأحاديث الكبيرة وملفات القصص تُقرأ حاليًا من الملفات الثابتة المراجعة؛ استيرادها إلى Supabase يجهّز التخزين فقط. نشر تحديثات لها يتطلب تصدير الإصدار الجديد إلى الملفات وإعادة البناء، أو إضافة مسار إدارة ومزامنة مستقل لاحقًا. لا توجد شاشة إدارة أو حسابات وهمية.

لا يزال الربط غير مفعّل، ولم يُنفّذ السكربت على أي مشروع Supabase.

## الخصوصية وإمكانية الوصول

تقدّم الأذكار يومي ومحلي، وخيارات القراءة محلية. البحث لا يُرسل إلى خدمة خارجية. يتوقف الصوت عند مغادرة القارئ، وتوجد معالجة لفشل الصوت والنسخ والتحميل. حوار الحديث يدعم Escape والتركيز، والقوائم والعدادات مسمّاة لقارئات الشاشة، والحركة تقل مع إعداد تقليل الحركة.

WebMCP: توفر صفحة الأذكار أداة `increment_dhikr` عند دعم المتصفح للواجهة. تستخدم العداد نفسه وتتحقق من المعرّف؛ عدم دعم المتصفح لا يعطّل الموقع.
